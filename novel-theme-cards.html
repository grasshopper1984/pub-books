04风格是如何叠加的

依据 themes.json、themes.css、reader.css、reader.js 与编译脚本整理。

装帧决定整书纸面、文字与字体，场景主题叠加局部色调。阅读器把当前装帧写入根元素的 data-book-style，每个场景则通过 data-theme="t…" 取得自己的底色、边线色与强度。两层可以独立组合，共有 5 × 108 = 540 种装帧与场景搭配。

01 / BOOK STYLE

根元素切换全局配色

reader.css 默认使用经典风格。科幻、浪漫、奇幻、简约通过 :root[data-book-style="…"] 覆盖 --canvas、--paper、--ink 等变量；科幻与简约使用无衬线字体，奇幻另设衬线字体。

02 / SCENE THEME

局部渐变叠在纸面之上

themes.css 把每个场景 ID 映射为 --scene-tint、--scene-accent 和 --scene-strength。场景以 115° 渐变铺色，在渐变轴 90% 处变为透明；场景本身不改正文的 --ink。

03 / READER CONTROL

切换时更新属性并记忆偏好

reader.js 响应装帧、字号和场景色开关，将值写入根元素的属性或 CSS 变量。原阅读器使用 localStorage 按书籍保存偏好；关闭场景色时，同时撤去渐变并还原普通边线。

十倍增强的准确含义与边线规则

这里的 alpha 是不透明度：0 完全透明，1 完全不透明。原值很低，表示透明程度很高。本图卡只将场景的 strength 乘以 10 并限制在 1 以内；RGB、渐变方向、90% 透明终点、装帧实色与正文颜色均保持原规则。增强后的色卡用于辨认颜色，不代表原书的阅读浓度。

/* 原阅读器 */
.scene {
  background: linear-gradient(115deg,
    rgba(var(--scene-tint), var(--scene-strength)),
    transparent 90%);
  border-top-color: color-mix(in srgb,
    var(--scene-accent, var(--line)) 18%, var(--paper));
}

/* 本图卡：只替换渐变起点的 alpha */
displayAlpha = Math.min(1, theme.strength * 10);
// 例：t007  rgba(154, 191, 161, 0.045)
//       →  rgba(154, 191, 161, 0.45)
// t001 的 strength = 0，十倍后依旧为 0。

边线的 18% 是场景边线色与纸面的混色比例，原公式为「18% 场景 accent + 82% paper」，本图卡保持这一比例。卡片中的两枚小色片显示 tint 和 accent 的原始实色，便于核对色号；它们不是渐变与混色后的最终颜色。即使 t001 的背景完全透明，启用场景色时仍会保留原来的混色边线。
